BLE UART Debug Console
建議協定：Browser → micro:bit 使用一行一命令並以 \n 結尾。
BLE 內部優先使用 compact protocol：R + 10×4-digit RC、P=PAIR、U=UNLOCK、E=ESTOP、Q=PING。
舊版 RC,... / CMD,... 仍可由 micro:bit 相容解析。
micro:bit → Browser 可回傳 STATE,CH,37、STATE,ACK,1、DBG,...；飛機 ACK Payload 會轉成 TEL,ATT、TEL,PWR、TEL,ALT 等資料並顯示在上方 Ground Station。
「顯示 Debug 訊息」會送 D0/D1，直接控制 micro:bit 是否產生 DBG,...；「回傳飛機姿態」與 Telemetry 選項會送 compact subscription mask，直接控制 micro:bit 哪些資料要經 BLE UART 傳回。飛機端原本的 ACK Payload 循環不變。
